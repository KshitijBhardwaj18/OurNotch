# OurNotch social media kit

Made from the website's own characters, notch and type. Prices and claims match ournotch.app.

| File | Size | Use |
|---|---|---|
| `hero.png` | 1080×1080 | Launch post (square) |
| `note.png`, `emoji.png`, `mood.png`, `photo.png` | 1080×1350 | Feature posts or one carousel |
| `private.png`, `price.png` | 1080×1350 | Privacy and pricing posts |
| `story.png` | 1080×1920 | Instagram / WhatsApp story |
| `demo-feed.mp4` | 1080×1350, 43 s | Feed video (Instagram, X, LinkedIn) |
| `demo-story.mp4` | 1080×1920, 43 s | Reels, TikTok, Shorts, Stories |
| `logo/ournotch-mark.svg` | vector | The logo mark, any size |
| `logo/ournotch-app-icon-1024.png` | 1024×1024 | App icon, transparent corners |
| `logo/ournotch-logo-light.png`, `-dark.png` | horizontal | Logo with the wordmark, for light / dark backgrounds |
| `logo/ournotch-profile-1080.png` | 1080×1080 | Profile picture (safe for circle crops) |
| `logo/ournotch-favicon-512.png` | 512×512 | Favicon, small spaces |

To change or add a graphic: run the website (`npm --prefix website run dev`), open
http://localhost:3000/social to see every card (that page only exists on the dev server), edit
`website/app/(en)/social/page.tsx`, and capture again.
